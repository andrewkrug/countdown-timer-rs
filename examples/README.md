# Examples

Shell scripts demonstrating `countdown-timer-rs`. Each builds the release
binary if needed, then drives it.

| Script         | What it does                                      |
| -------------- | ------------------------------------------------- |
| `quick.sh`     | 10-second timer — fast smoke test of the build    |
| `tea.sh`       | 3-minute steeping timer                           |
| `pomodoro.sh`  | Full Pomodoro cycle: 4 × (25 min work + break)    |

Run from the repo root:

```bash
./examples/quick.sh
```
